### Write a program that displays the current year, **2025**, and a smiley face, **😅**. Each message should be on a separate line.

#### - **Requirements:**

- The program should display the number 2025.
- The program should display the smiley face, 😅.
- The number 2025 and the smiley face, 😅, should be displayed on separate lines, not on the same line.
- To display messages on the screen, use the System.out.println command.
